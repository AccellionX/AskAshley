# Ask Ashley Prototype

Personal brand one-page site for **Ashley Russo**, Wealth Management Advisor and founder of Russo Wealth Management. Built with Astro + Tailwind CSS (static output). Newsletter form is visual only.

## Run locally

```bash
cd askashley-prototype
npm install
npm run dev
```

## Deploy to Vercel

Connect this folder as the project root (or set Root Directory to `askashley-prototype`). Zero config — Vercel detects Astro automatically. Build command: `npm run build`. Output: `dist/`.
